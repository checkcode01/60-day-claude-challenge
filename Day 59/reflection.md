# Reflection

Completing the 60-Day ABTalks Challenge transformed my understanding of AI-assisted application development.

If I started again today, during the first week I would focus on learning HTML, CSS, JavaScript, GitHub, prompt engineering, and project organization before building applications.

During the second week I would spend more time creating reusable UI components instead of rewriting code for every project. I would also standardize prompts and improve documentation from the beginning.

During the final phase I would prioritize product quality over feature quantity. I would add better testing, accessibility improvements, responsive layouts, and error handling. I would also collect user feedback earlier and continuously refine the applications.

The most valuable lesson was that AI accelerates development, but good product thinking, prompt engineering, and user experience determine whether an application is genuinely useful.

RecognitionIQ demonstrated how AI can automate recognition workflows while improving consistency and reducing manual effort. Future enhancements would include Teams integration, approval workflows, analytics dashboards, and enterprise authentication.

Overall, this challenge significantly strengthened my confidence in building AI-powered products despite coming from a non-software engineering background. It reinforced that structured problem solving, continuous learning, and iterative improvement are more important than writing every line of code manually.
