# Day 2 - What Is Prompt Engineering

## Objective
Learned how prompt engineering improves AI responses.

## Lazy Prompt

Explain how artificial intelligence works.

## Engineered Prompt

Act as an experienced AI educator.

Explain how Artificial Intelligence works to a complete beginner.

Requirements:
- Use simple language
- Start with a one-sentence definition
- Explain Machine Learning, Deep Learning, and Generative AI separately
- Include a real-world example for each
- Use headings and bullet points
- End with a summary table
- Keep the explanation under 500 words

## Observations

### Lazy Prompt Output
- Generic response
- Less structured
- Fewer examples

### Engineered Prompt Output
- Clear structure
- Better explanations
- More useful examples
- Professional formatting

## Key Learnings

1. Prompt engineering improves response quality.
2. Giving context reduces ambiguity.
3. Defining a role improves expertise.
4. Specifying output format creates organized results.
5. One good prompt saves time and follow-up questions.

## Tools Explored

- Claude AI
